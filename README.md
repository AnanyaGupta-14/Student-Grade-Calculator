# 🎓 Student Grade Calculator

My first Java basic project — created a **Student Grade Calculator** using Java.

## 📌 About the Project

This is a simple console-based Java application that takes a student's marks in 5 subjects and calculates:

* Total Marks
* Percentage
* Grade
* Pass/Fail Result

## 🛠️ Concepts Used

* Java Basics
* Variables
* Data Types
* `Scanner` for User Input
* Arithmetic Operators
* `if-else` Statements
* Conditional Logic
* Basic Input/Output

## ▶️ How to Run

1. Clone or download the repository.
2. Open the project in your Java IDE.
3. Run `StudentGradeCalculator.java`.
4. Enter the student's name and marks when prompted.
5. View the calculated result in the console.
